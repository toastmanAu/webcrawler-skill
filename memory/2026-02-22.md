## Fan Controller
- Orange Pi 5 in a 3D printed case with 2-pin 5V fan via MOSFET
- Script: /home/phill/fan-control/fan-control.py
- Using GPIO1_C4 (gpio52, sysfs software PWM at 25Hz)
- DT overlay attempted for hardware PWM1_M2 but u-boot-update didn't apply it correctly
- Service installed and running: sudo systemctl status fan-control
- Temperature curve: off <40°C, 25% at 45°C, linear to 100% at 78°C
- The Orange Pi 5 has a 26-pin header (not 40-pin)
- pwmchip0=PWM2(fd8b0020), pwmchip1=PWM6(febd0020) — neither on header
- Hardware PWM pins on header: GPIO1_C4=PWM1_M2, GPIO1_D3=PWM0_M1
