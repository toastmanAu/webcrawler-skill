## Key lesson: CCC/Spore tx fee pattern
- `createSpore`, `meltSpore`, `transferSpore` all return `{ tx }` with fees NOT completed
- Always call `await tx.completeFeeBy(signer, 1000n)` before `signer.sendTransaction(tx)`
- This applies to all spore SDK functions — not just meltSpore
