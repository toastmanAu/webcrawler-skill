### Bitcoin LoRa Relay (new design)
- secp256k1 shared curve = same key works on both chains
- Device → LoRa (fully signed BTC tx) → Gateway → CKB relay cell
- Gateway: zero keys, pure broadcaster — cannot steal
- CKB type script: verifies secp256k1 sig natively, replay protection via nonce cell
- Option C (SF12 range): pre-publish tx to CKBFS, 11-byte LoRa trigger
- RGB++ atomic delivery: BTC UTXO conditional on CKB relay confirmation
- Cost: 0.006 CKB permanent, ~385 CKB temporary working capital

### Light Client Security
- "If crypto validates, it's correct" — no additional assurance needed
- ESP32-P4 hardware eFuse for key security
- Layer 2 (PoW): Eaglesong in repo, needs wiring (~150 lines)
- Layer 3 (Merkle): Blake2b in repo, needs wiring (~80 lines)
- Full stack adds ~21KB to binary → ~235KB total

### MMR Snapshots (fast-sync design)
- 768-byte proof proves any block is canonical (24 Blake2b ops)
- Snapshot cell: 254 CKB, ephemeral TTL
- Power-on sync: verify MMR proof → download 10k headers → Eaglesong → ~2 seconds
- Local state: 4KB RAM total — complete verification state
- Stronger than Bitcoin SPV: proves canonical chain, not just PoW

### Gateway Cell Economics
- One cell per machine, operator-owned, recoverable deposit
- Firmware: governance multisig allowlist (not manufacturer whitelist)
- Home builds valid if firmware approved + proofs pass
- Anti-Helium: allowlist means governance capture can't revoke existing gateways
