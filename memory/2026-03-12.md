### Agent Architecture Discussion
- FiberQuest core = deterministic state machine, no LLM needed at runtime
- RAM value → rule check → Fiber payment: pure code, could run on a microcontroller
- LLM adds value at: game library creation (RAM address mapping), edge cases (dispute resolution), meta layer (scheduling, channel management)
- Valid to call it an "agent" — makes autonomous financial decisions, interprets game state, manages funds without human oversight. Intelligence in the design, not inference.
