### What We Learned

**CKB Data Field Trick:** Tournament ID embedded in tx data field = no off-chain lookup needed. Agent extracts during polling, full audit trail on-chain via JoyID SDK integration.

**Transaction Building:** Three methods documented:
1. CCC SDK (recommended) — automatic
2. Manual assembly — full control
3. ckb-cli (CLI) — command line

All handle tournament ID in data field transparently.

**Dual-Signer Pattern:** SignerFactory allows testnet MVP (direct private key) to switch to mainnet-safe SuperRise (wallet isolation) with only .env change.

**X11 on Pi Headless:** Electron needs a display (X server). Pi has X running but SSH sessions can't access it easily. For tonight, we focused on the agent API (curl-testable). Electron app wired and ready — just needs monitor connection to start.
