## LoRa PoC — Key Design Decisions (session 2026-02-25/26)
- Two-token model: POC Token (RF payment) + CKB (ephemeral escrow only)
- 4KB RAM = complete chain state for 18.75M block history via MMR
- MMR snapshot cells (254 CKB, ephemeral): enable ~2s cold-boot sync
- Gateway cells: owner-controlled, recoverable deposit, firmware via governance multisig allowlist
- Anti-Helium: allowlist (not latest-only) means governance capture can't revoke existing gateways
- Bitcoin LoRa relay: secp256k1 shared curve, fully signed BTC tx over LoRa, CKB relay cell verifies sig natively
- Option C (SF12): pre-publish BTC tx to CKBFS, 11-byte LoRa trigger — max range, min battery
- RGB++ atomic delivery: BTC UTXO conditional on CKB relay confirmation
- Per-Bitcoin-relay cost: 0.006 CKB consumed permanently (~$0.000009 today, $0.006 at $1/CKB)
