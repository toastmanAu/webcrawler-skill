### Key technical insight
- `navigator.brave.isBrave` is a **Promise** (async) — calling without `await` returns truthy function object
- Must use `typeof navigator.brave !== 'undefined'` for synchronous Brave detection
- `authWithRedirect()` navigates whole tab to `app.joy.id` — no WebSocket relay, no QR scanning
- Result returns as `?_data_=` + `?joyid-redirect=true` params on `redirectURL`
- `authCallback()` parses result from current URL
