## WyTerminal Flash Issue — Power Brownout
- T-Display S3 **dies at ~17% through flash** every time on Pi USB
- Small writes (bootloader, partitions) succeed; 1.2MB firmware blob causes USB dropout
- Root cause: Pi USB port can't supply enough current during sustained flash write
- **Fix**: power board from second USB-C port (bottom = native USB) on EliteDesk/battery bank
  - Top USB-C = UART (flash comms to Pi)
  - Bottom USB-C = power only (to EliteDesk or battery)
- `--before no_reset` required since board manually held in boot mode

### v3 Architecture
- `/deploy` command: types `curl -fsSL https://wyltekindustries.com/wyterminal/install.sh | bash` via HID on target → installs wyrelay.py + udev rules → relay starts on target
- Boot: checks `192.168.7.1:7799` (USB net) first → falls back to `RELAY_URL` (WiFi Pi)
- Every 15s: re-checks if USB relay came up
- Header shows `USB` (orange) or `WIFI` (green) to indicate active relay path
- True plug-and-play: plug into any Linux machine → `/deploy` → shell works
