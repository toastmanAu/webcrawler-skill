## WyMesh — Concept Crystallised (2026-03-11 ~01:15 ACST)

Working name: **WyMesh** (or CKB Mesh / ProofNet — TBD)

### Core Concept
A decentralised IoT mesh network where physical relay nodes earn CKB for useful work (packet relay, coverage provision) with hardware-level trust anchored on-chain via CKB DOBs.

### Stack
- **Hardware**: ESP32 + SX1276 LoRa (TTGO LoRa32 ~$15, solar-chargeable)
- **Mesh protocol**: Meshtastic (open source, ESP32-native, active community)
- **Identity**: ATECC608A secure element — unforgeable device keypair (~$1)
- **On-chain identity**: DOB minted per device containing pubkey + firmware hash + HW revision
- **Transport auth**: WyAuth redirects routed over LoRa mesh → gateway → JoyID → back
- **Proof**: "Proof of Coverage" / "Proof of Relay" — signed witness reports submitted to CKB
- **Validation**: Type script checks firmware hash IN approved whitelist cell before paying
- **Rewards**: Fiber micropayments per packet relayed or per uptime epoch
- **Settlement**: CKB L1 anchors node registry, staking, whitelist governance

### Firmware Trust Model
- Device DOB contains firmware hash at flash time
- Whitelist cell (governed by multisig/community) = approved firmware hashes
- Type script: `device_dob.firmware_hash IN whitelist AND proof.signature.valid`
- Wrong firmware hash = proof rejected = no reward
- Firmware update = new hash added to whitelist cell; old versions can be revoked
- No centralised firmware server, no manufacturer backdoor

### WyAuth Integration
- LoRa mesh becomes a transport layer for WyAuth sign requests
- Device with no WiFi authenticates via mesh → gateway → JoyID → back
- Relay nodes earn CKB for forwarding WyAuth packets too
- Geographic routing: Fiber channels between mesh nodes in different cities

### Why CKB
- Cell model = perfect for coverage proof cells (compact, composable)
- CKBFS = permanent coverage map storage, verifiable by anyone
- Fiber = micropayment throughput for per-packet rewards
- DOB = transferable device identity with provenance history
- Type scripts = trustless firmware verification, no central authority

### Key Insight
"Not a validator, not a traditional miner — a physical infrastructure participant. The transport layer has geography. You can prove a message traversed a specific region of the planet."
