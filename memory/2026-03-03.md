## CCC 1.x Lessons (CRITICAL — write into every future CKB web app)
- Start with @ckb-ccc/spore, NOT spore-sdk + Lumos
- Lumos common-scripts only resolves secp256k1 — JoyID uses custom lock → "not enough capacity"
- Correct mint sequence: `createSpore → tx.completeFeeBy(signer, 1000n) → signer.sendTransaction(tx)`
- useCcc() must be INSIDE Provider (different component, not same)
- 1.x API: `{ signerInfo, open, setClient, disconnect }` — signer = `signerInfo?.signer`
- Switch networks: `setClient(new ccc.ClientPublicTestnet())`
- Shadow DOM modal: inject style into shadowRoot for mobile sizing
- iOS Safari: needs HTTPS for WebAuthn/JoyID passkeys

### DOB Storage Decision — CKBFS + DOB/1
- Founding Member DOBs: **DOB/1** standard (render patterns, more flexible)
- Image storage: **CKBFS** (witnesses-based, native on-chain, no IPFS/BTCFS dependency)
- CKBFS cost: ~61 CKB per DOB (vs ~78,066 CKB naive cell storage for 78KB image)
- CKBFS JS implementation needed before mainnet mint (research task queued)
- Text DOB test ready to run now — costs ~150-300 CKB from testnet balance

### On-Chain Storage Cost Reference
- 1 byte = 1 CKB minimum capacity (locked permanently)
- Small RFC (~24KB): ~149 CKB total (24 data + ~125 cell overhead)
- Large RFC (~90KB): ~90 CKB data + overhead
- 78KB image (naive): ~78,066 CKB — unaffordable per DOB
- CKBFS witnesses path: ~61 CKB regardless of image size — this is the play
