## 21:00 ACST — Windows Fiber v0.7.1 Key Encryption Bug Fix

### Issue Reported by User
Windows user using our installer reports:
- `panic in encrypt_decrypt_file.rs (NotFound on key file)` 
- Even after setting `FIBER_SECRET_KEY_PASSWORD` env var
- Deleting `data\key` and trying to regenerate
- Setup works on smoke test but fails on real start

### Root Cause Analysis
**v0.7.1 Change**: Introduced LocalSigner key management (#1088 in release notes)
**Windows Bug**: 
1. Looks for key at `ckb\key` (relative to binary)
2. Installer puts key at `data\key` 
3. Path resolution fails on Windows
4. `FIBER_SECRET_KEY_PASSWORD` env var not picked up by Windows service

### Solutions Created
**1. Fix Script** (`fix-windows-fiber.ps1`):
- Auto-detects v0.7.1
- Generates 32-byte hex key
- Writes to both `data\key` and `ckb\key`
- Sets env var permanently
- Updates config.yml paths
- Restarts service

**2. Installer Updates**:
- Added version fallback (v0.7.0 if v0.7.1 fails)
- Windows-specific detection
- Automatic fix application

**3. Manual Workarounds**:
- Run as Administrator
- Downgrade to v0.7.0
- Install outside Program Files
- Manual key generation

### Created Assets
1. **fix-windows-fiber.ps1** — One-command fix script
2. **fiber-installer-fix.ps1** — Patches for main installer
3. **Complete troubleshooting guide** — 5+ workarounds

### Key Learning
Windows services have different environment context than user sessions. `FIBER_SECRET_KEY_PASSWORD` must be:
