## Crypto-Dash Timezone Fix (17:14-17:24 ACST)
**Root Cause Identified:** Binance API returns timezone-aware datetimes (`datetime.fromtimestamp(..., tz=timezone.utc)`), but DuckDB's `TIMESTAMP` column stores naive datetimes. When tz-aware timestamps were inserted, DuckDB converted them silently using the NucBox system timezone (UTC). Later, when the code tried `now_utc - last_ts`, one was aware and one was naive — boom.

**Fix Applied:** One-line change in `src/storage/db.py:upsert_ohlcv()`:
- Strip timezone before inserting: `r["ts"].replace(tzinfo=None) if r["ts"].tzinfo else r["ts"]`
- Ensures all stored timestamps are naive

**Verification:** Universe job completed without OHLCV errors. API now returns real scores:
- BTC: score 58.53, tier B, all indicators populated ✅
- Analysis page now live with indicator data

**Status:** Fixed. Dashboard fully operational.
