### Inner-length framing (IMPORTANT)
Tentacle wraps all protocol messages with a **4-byte BE length prefix** inside the Yamux DATA payload:
`[yamux header 12B][4-byte BE msg_len][molecule message]`
This applies to both ProtocolInfo negotiation and LightClient messages.

  - `src/main.cpp` — full sketch
  - `platformio.ini` — build config

### Screen flow
1. **LoRa Scan** — sweeps AU915 channels (915.2–918.2 MHz), draws live RSSI bar chart per channel, listens for CKB-LoRa beacon packets (magic 0xCB 0x01 + name + block number)
2. **Node Select** — lists found nodes with RSSI bar, SNR, block number, CKB badge; W/S to scroll, ENTER to select
3. **Main** — GM861S scans QR → validates CKB address (ckb1/ckt1 prefix + bech32 charset) → queries WiFi RPC for balance; N=edit RPC URL, Q=re-scan LoRa

- SX1262: SCK=40, MISO=38, MOSI=41, CS=9, RST=17, DIO1=45, BUSY=13
