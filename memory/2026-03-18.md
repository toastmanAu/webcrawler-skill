## Fiber Node Biscuit Auth — Definitive Reference (2026-03-18)
- Source: https://docs.fiber.world/docs/guide/biscuit-auth (saved locally)
- If `biscuit_public_key` absent in config → RPC open (no auth) — safe for localhost
- Fiber REFUSES to start if bound to public IP without auth enabled
- Setup: `cargo install biscuit-cli --vers 0.6.0-beta.2` → `biscuit keypair` → add pubkey to `rpc.biscuit_public_key` in config.yml
- Token permissions: Datalog facts e.g. `write("channels")`, `read("peers")`, expiry via `check if time($time), $time <= 2026-01-01T00:00:00Z`
- `get_balance` is NOT an RPC method — balance must be queried via CKB chain RPC directly
